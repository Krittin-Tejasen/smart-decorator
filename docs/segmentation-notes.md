## เกณฑ์ที่ใช้ตัดสิน

ทุกชิ้นที่ segment ออกมาจะถูกส่งไป product matching (แปลง label เป็นประเภท แล้วใช้ภาพโปร่งใสบนพื้นขาวเข้า CLIP)
เกณฑ์จึงเป็น **หนึ่ง mask ต้องมีเฟอร์นิเจอร์ชิ้นนั้นชิ้นเดียว และต้องครบ** ตัดสินจากภาพตัดทีละชิ้น ไม่ใช่จากภาพรวมทั้งห้อง
และ mask ที่ใหญ่กว่าไม่ได้แปลว่าดีกว่า

## pipeline ปัจจุบัน

1. **Grounding DINO** (`grounding-dino-tiny`) ตรวจจับด้วยรายการคำใน `_FURNITURE_PROMPT` และรันอีกรอบด้วย prompt `doorway` เพื่อหาช่องประตู
2. **SAM 2** (`sam2.1_hiera_small`) ใช้แบบ mask เดียวบนกล่องของ DINO (`SAM_BOX_PAD=0`, `SAM_MULTIMASK=0`) ยกเว้นเตียง ที่ใช้ผลรวมของตัวเลือกทั้ง 3 ตัว
3. **`clean_mask`** ลบเศษก้อน และไม่อุดรู
4. **`select_detections`**
   - ทิ้งของที่เห็นผ่านช่องประตู
   - dedupe โดยดูจาก mask
   - รวมส่วนประกอบเข้ากับชิ้นหลัก (หัวเตียง, ฐานเตียง, เบาะเก้าอี้, หมอน, ผ้าห่ม)
   - ตั้งชื่อโต๊ะเล็กข้างเตียงเป็น nightstand
5. **`_settle_masks`** แบ่งพิกเซลที่ซ้อนกัน ลบออกจากชิ้นที่อยู่ข้างหลังเท่านั้น และไม่เพิ่มให้ใคร
6. **`relabel_with_clip`** (`clip-ViT-B-32` ผ่าน sentence-transformers) เปลี่ยนชื่อเฉพาะเมื่อผ่านทุกข้อ:
   - ข้ามหมวดตามคู่ที่ DINO ผิดบ่อยเท่านั้น
   - ความน่าจะเป็นของชื่อใหม่อย่างน้อย 0.6
   - มั่นใจกว่าชื่อเดิมอย่างน้อย 5 เท่า

## การตัดสินใจหลักและเหตุผล

| การตัดสินใจ | เหตุผล |
|---|---|
| ไม่ใช้การขยายกล่องและการเลือก mask ตัวใหญ่สุดของ patch แรก | ส่วนที่ได้เพิ่มมาส่วนใหญ่คือผนัง พื้น ต้นไม้ด้านหลัง และหมอน การขยายกล่องแทบไม่ได้ช่วยเก็บขาเก้าอี้ |
| ไม่อุดรูใน mask | รูมักเป็นผนังที่มองผ่านตัวเฟอร์นิเจอร์ เช่น ชั้นวางโปร่ง |
| หมอนและผ้าห่มรวมอยู่กับโซฟาหรือเตียง | ภาพสินค้าในฐานข้อมูลก็มีหมอน และ matching ดู label ก่อน การตัดหมอนออกทำให้โซฟามีรู และเบาะเก้าอี้หลุด |
| เตียงใช้ผลรวมของตัวเลือก SAM 2 | mask เดียวไม่มีหัวเตียง แต่ตัวเลือกทั้ง 3 รวมกันครบ จึงไม่ต้อง train เพิ่ม |
| พรมอยู่ข้างหลังเสมอ | พรมไม่ควรแย่งฐานเตียงหรือขาเก้าอี้ ส่วนพรมเองใช้แค่สีในการ match ก็พอ |
| CLIP เปลี่ยนชื่อเฉพาะข้ามหมวด | ถ้าเลือกจากทุกคำ ตรงกับ DINO แค่ 39% ส่วนในหมวดเดียวกันผิดพอๆ กับถูก แบบที่ใช้จริงแก้ได้ 11 จาก 12 ชิ้น |
| ของในสวนยังหลุดมา 1 ห้อง | ยอมรับได้แล้ว ตามที่ตกลงกัน |
| ยังไม่ fine-tune โมเดล | ปัญหาหลักแก้ได้ด้วยกฎ ส่วนการ train ต้องวาด mask ด้วยมือจำนวนมาก |

## รันซ้ำ

```powershell
cd backend
.\.venv\Scripts\python.exe -m pip install -r requirements.txt   # torch แบบ CUDA 12.8 สำหรับ RTX 50-series:
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
# checkpoint: backend/checkpoints/sam2.1_hiera_small.pt (ดูวิธีดาวน์โหลดหัวไฟล์ segmentation.py)
.\.venv\Scripts\python.exe -m unittest discover -s tests
.\.venv\Scripts\python.exe compare_segmentation.py <ภาพห้อง...>
# ได้ compare/<name>_compare.png (ทั้งห้อง) และ compare/<name>_items.png (ทีละชิ้น)
```

env ที่เกี่ยวข้อง: `SEGMENTATION_CLIP_RELABEL=0` ปิด CLIP, `SAM_MULTIMASK=1` / `SAM_BOX_PAD=0.05` เปิดพฤติกรรมของ patch แรก

output ของ 56 ห้องอยู่ที่ `backend/compare/all_rooms/` และ `all_rooms.zip` (306 MB) ไฟล์เหล่านี้ไม่อยู่ใน git
ต้องย้ายไปเครื่องอื่นเอง ภาพห้องทดสอบชุดนี้ก็ไม่อยู่ใน repo เช่นกัน

## ที่ยังค้าง

- หัวเตียงบางหลังยังมีรอยแหว่ง (ห้อง 22, 40) และเตียงในภาพความละเอียดต่ำยังไม่ครบ
- โต๊ะกลางบางตัวยังชื่อ console table หรือ ottoman, ตู้ไซด์บอร์ดบางตัวยังชื่อ dresser หรือ bookshelf
- เกณฑ์ทั้งหมดปรับจาก 56 ห้องนี้ ควรวัดกับชุดทดสอบที่มีคำตอบถูกต้อง เช่น วาด polygon ใน Roboflow แล้ว export เป็น COCO
  - วาดเฉพาะส่วนที่มองเห็น
  - แก้ขอบที่ Smart Polygon วาดให้เองทุกชิ้น
  - ใช้ห้องชุดใหม่ที่ไม่ได้ใช้ตอนปรับเกณฑ์
- ต้องคุยกับคนทำเรื่องวัดขนาด (`feature/furSize`): โมดูลนั้นวัดจากขอบล่างของ mask ชิ้นที่ถูกบังหรือไม่ได้วางบนพื้นจะวัดผิด ทางที่เสนอคือเพิ่ม field อย่าง `bottom_occluded` ให้ขั้นวัดขนาดรู้ว่าชิ้นไหนวัดไม่ได้
- integrate กับ feature extraction ของเพื่อนในกลุ่ม แล้วรันเทียบอีกครั้ง
